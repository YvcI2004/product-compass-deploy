# 选品罗盘（v8 AI 作图工坊版）

跨境电商选品情报工具：**对标紫鸟浏览器的专业 SaaS**——打开即入工作台，只做商品类目分析。
企业蓝主色 + 深蓝侧栏 + 线性 SVG 图标，图表化仪表盘 + 工作流五页 + **AI 作图工坊**。
前端静态站（Vite + 原生 JS，图表为手写 SVG 零依赖）+ Python 后端（Flask），
本地运行；v8 起后端接 LinkFoxAI（紫鸟算力）开放接口出图、出文案。

## 启动

> **一键启动（推荐）**：双击项目根目录的 `启动选品罗盘.bat`（桌面也有同名快捷方式）——
> 自动检查 8000/5173 两个端口，缺哪个补哪个，最后自动打开浏览器。重启电脑、
> 误关了黑色窗口之后，双击它就行，不用记命令。

**后端**（数据功能必需）：

```powershell
cd D:\claude-projects\product-compass\api
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

**前端**（另开一个终端，在项目根目录）：


## 🛰️ 关键词雷达 · 工作流

1. **添加关键词**：你关注的类目词（如 dog bed），随时可加，不定期采集
2. **每轮采集 5 个数**（约 2 分钟）：打开 amazon.com 搜索该词 →
   抄搜索结果数；打开第 1 名商品页 → 抄 BSR、评论数、价格、最新评论距今天数
3. **差值引擎自动干活**：打分、对比上一轮、生成中文动态告知
   （「竞争缓解，切入窗口」「B 类 → A 类 🎉」「头部评论 +200，类目在真实出货」…）
4. 从第 2 轮起，工作台重点机会榜单自动出现涨跌标记 ↑↓

### 类目机会指数公式（api/radar.py，权重可调）

```
类目机会指数 = 35×需求规模 + 25×竞争友好度 + 20×市场活跃度 + 20×价格空间
  需求规模   头部商品 BSR → 经验曲线换算预估月销（与 ASIN 分析同表）
  竞争友好度 搜索结果数：≤1,000 稀缺 → 1.0；>100,000 红海 → 0.05
  市场活跃度 头部最新评论距今天数：1 天内极活跃 1.0；30 天以上休眠 0
  价格空间   头部价格 $15–45 黄金带 1.0；<$8 利润太薄 0.2
≥75 → A 类；≥55 → B 类；否则 C 类（阈值同 ASIN 分析，口径一致）
```

### 接口

- `GET    /api/radar`              雷达全量（关键词 + 采集轮次 + 动态）
- `POST   /api/radar/keyword`      添加监控关键词 `{keyword}`
- `POST   /api/radar/collect`      提交一轮采集 `{keyword_id, results, bsr, reviews, price, days}`
- `DELETE /api/radar/keyword/{id}` 删除关键词（连同轮次与动态）

数据持久化在 `api/pipeline/generated/radar.json`；差值引擎自测：`python radar.py`。
关键词卡片上的「简报 PDF」把该词全部轮次 + 相关 ASIN 分析 + 综合结论排成一页 PDF。

## 🔍 ASIN 分析 · 验证单品（v7.3 起智能模式）

客户发来 Amazon 美国站链接/ASIN → **商品页 Ctrl+A → Ctrl+C 整页粘贴 → 自动提取**（约 10 秒，
识别 ASIN + 预填标题和 6 个数字，绿色=已提取、琥珀=没认出来手补；也可以完全手动填）→
生成五维报告（需求 35 + 竞争 25 + 活跃 20 + 痛点 10 + 价格 10）→
**导出 PDF**（浏览器打印 → 另存为 PDF）或**复制文本**直接发微信。

- **整页粘贴**：接口 `POST /api/extract`（api/extract.py，纯文本正则提取，零网络请求；
  粘贴内容可能含个人信息，不落盘不打日志）。搜索页粘贴只提取结果数并提示
- **缺数推补**：价格/评分/评论数/结果数/评论天数没填时按「中性市场」默认值继续算
  （刻意选中性档，不给推补品白送分数），报告挂**置信度徽章**（数值+文字，≥90 高/≥75 中高/≥60 中/<60 低），
  每个推补数字在维度和依据里都标「（推补值）」；利润弹窗遇推补价格会提示核实。
  链接/名称/关键词/BSR 仍然必填，填了但非法照样报错
- **风险旗标 + 行动建议**：评论护城河 / 疑似大牌 / 季节性 / 价格偏离自动亮旗；
  由最弱两维 + 旗标生成至多 3 条行动建议，随报告展示并进 PDF/复制文本
- 保险丝：`api/analyzer.py` 顶部 `INFER_ENABLED = False` 可一键关掉推补逻辑，回到「五项全填才给算」
- 接口：`POST /api/analyze`、`POST /api/extract`、`GET /api/analyses`、`DELETE /api/analyses/{id}`
- 同一关键词的多个 ASIN 自动归成类目对比排名，含毛利率列；含推补值的记录历史表带琥珀圆点
- 自测：`python analyzer.py` 四场景（全量/只填核心四项/单缺天数/无评论新链接）、`python extract.py` 提取断言
- **行为变更**（v7.3）：「最新评论距今天数」缺失不再报错（有评论时按 7 天推补并扣置信度）

## 🎨 AI 作图工坊 · 紫鸟算力接驳（v8，api/linkfox.py）

把已有的 LinkFoxAI（紫鸟）算力变成罗盘里的出图/出文案能力。后端纯标准库 urllib 调
`https://ai-api.linkfox.com`，前端只跟 `/api/linkfox/*` 打交道，**API Key 永不出后端**。

| 功能 | 端点 | 点数 |
|---|---|---|
| 自动抠图（商品/人像/服饰/头发/人脸） | `/image/v2/make/cutout` | 10/张 |
| 场景裂变（写实/简约/智能） | `/image/v2/make/sceneFission` | 20/张 |
| 相似图裂变（控比例/相似度） | `/image/v2/make/imageToImage` | 20/张 |
| 智能修图（KONTEXT / GPT 系 / Qwen 等模型） | `/image/v3/make/imageEdit` | 动态计费 |
| 换模特（头部图必填，可带场景参考） | `/image/v2/make/changeModel` | 20/张（原分辨率 25） |
| AI 文案（报告页「AI 写话术」） | `/v2/process/result/textGen/*` | 按 token，最低 1 点 |

- **花钱有闸门**：余额卡实时显示剩余点数/套餐到期日；每次提交前弹报价确认（预估 N 点），
  任务完成后回显**实耗点数**（以平台返回为准）；上传本地图、查余额免费不扣点
- **异步任务模型**：提交 → 存 `data.id`（按字符串处理防大整数丢精度）→ 每 10 秒轮询
  （文案 3 秒）→ 成功取 `resultList[].url`（8 小时有效，过期「换新地址」）
- **任务存档**：`api/pipeline/generated/linkfox_tasks.json` 最多 60 条，刷新页面历史还在
- **下载代理**：`GET /api/linkfox/download?url=…` 带域名白名单（只放行 linkfox 家图床），
  防止接口被当成任意 URL 下载器
- **错误中文化**：点数不足 / 审核未通过 / 套餐过期等官方错误码都翻成可操作的中文提示
- 自测：`python linkfox.py`（只调免费余额接口，不扣点）

## 💰 利润测算 · FBA 毛利模型（api/profit.py）

```
毛利额 = 售价 − 佣金（售价 × 佣金率，默认 15%）− FBA 配送费 − 采购成本 − 头程物流 − 其他
→ 毛利率 / 保本售价（= 除佣金外单件成本 ÷ (1 − 佣金率)）/ 月利润（× 预估月销）
红线：毛利率 < 20% 预警（跨境常规红线）；≥ 30% 为优
```

- 报告页「利润测算」打开弹窗：售价自动带入、**改任一数字实时重算**（前端公式与 profit.py 一致）
- 「存入报告」后测算随报告存档，出现在 PDF、类目简报和立项看板
- 监控总览的「快速测算」是不挂报告的独立速算
- 接口：`POST /api/analyses/{id}/profit`；自测：`python profit.py`

## 给客户交付的三种姿势

**A · 类目机会简报（PDF）**：雷达页「简报 PDF」→ 一页纸：指数、历史轮次、判断依据、相关 ASIN、综合结论
**B · 单品 PDF 报告**：ASIN 分析 + 利润测算 → 导出 PDF（含毛利/保本价/月利润）→ 微信发送
**C · 口头汇报**：监控总览的数据条 + 类目机会排行，30 秒讲清「哪三个类目在升、哪个竞争在加剧」

## 设计要点

- **为什么半自动**：Amazon 无免费官方数据接口，爬虫违反平台条款且不稳定；
  行业做法 = 人工小批量采集（或付费 API）+ 系统自动算差值。智能在计算，不在采集。
- **公式透明可调参**：所有打分维度、权重、阈值集中在 analyzer.py / radar.py 顶部，
  客户问起每一分都能讲清来源；两套公式同一世界观，口径一致。
- **数据都在本地**：analyses.json / radar.json 明文可查、可备份，不依赖任何云服务。
- **以后接 Keepa**（约 €49/月，ASIN 全量数据 API）：把「人工抄数」换成 API 查询即可，
  公式、差值引擎、报告模板全部不动；API 密钥只放后端，绝不进前端。
